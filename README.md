# BrightTV-Viewership-Analytics
## Overview

This project presents a **BrightTV Viewership Analysis case study** focused on identifying opportunities to increase the platform’s subscriber base and improve viewer engagement.

BrightTV’s CEO tasked the **Customer Value Management (CVM) team** with using data-driven insights to understand subscriber behaviour, content consumption patterns, and opportunities for growth. As the data analyst, I analysed the available dataset to uncover meaningful trends and translate them into actionable business recommendations.

The analysis was developed to support a **20-minute strategic presentation** covering four key areas:

*  **User & Usage Trends** — Analyse subscriber demographics, viewing behaviour, and consumption patterns across the BrightTV platform.
*  **Factors Influencing Content Consumption** — Identify patterns and factors associated with higher or lower levels of viewer engagement.
* **Content Recommendations** — Recommend content strategies that could increase viewing activity, particularly during low-activity periods.
* **Subscriber Growth Strategies** — Identify data-driven opportunities to attract new users, improve engagement, and support subscriber growth.

## Tools & Technologies

* **Databricks** — Data preparation, cleaning, transformation, and analysis
* **Excel** — Exploratory analysis, pivot tables, and data summarisation
* **Looker Studio (Data Studio)** — Interactive dashboards and data visualisation
* **Lovable** — Interactive presentation and dashboard development
* **ChatGPT** — Analytical support, insight development, and project documentation

## Project Outcome

The project demonstrates an end-to-end **data analytics workflow**, from data preparation and exploration to visualisation and strategic recommendations. The findings are designed to help BrightTV better understand its subscribers, optimise content engagement, and identify opportunities for sustainable subscriber growth.
